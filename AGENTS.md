# AGENTS

## Правила работы

### Git

1. Сообщения коммитов писать на русском языке.

### Workflow

1. Каждую новую фичу делать в отдельной git-ветке.
2. Перед отправкой изменений проверять локальные тесты.
3. Новые фичи сначала проверять в staging-окружении.
4. Для staging использовать отдельного Telegram-бота и отдельную базу данных.
5. Только после успешной проверки в staging выкладывать изменения в production.
6. Изменения, связанные со схемой базы данных, сначала проверять в staging на реалистичных данных или сценариях.
7. Новые команды, кнопки и пользовательские сценарии Telegram сначала проверять только в staging-боте.
